# Kubernetes Skill

## Quick Start

When working with Kubernetes, follow these best practices:

1. Cluster Health - Check node status, resource utilization, and system pods

2. Workload Management - Deploy, scale, and update applications using Deployments and StatefulSets

3. Troubleshooting - Inspect logs, events, and pod states to diagnose issues

## Common Commands

# Get cluster info
kubectl cluster-info
kubectl get nodes

# Manage workloads
kubectl get pods -A
kubectl describe deployment <name>
kubectl logs <pod-name> -f

# Apply configurations
kubectl apply -f manifest.yaml
