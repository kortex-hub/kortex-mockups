Why Kortex?

AI agents are powerful.
Uncontrolled agents are dangerous.

Giving an LLM access to your code, network, and credentials without guardrails is a recipe for disaster. Kortex gives you the power without the risk.

Without Kortex

  • Agents run with unrestricted access to your filesystem and network
  • API keys and credentials exposed directly to the LLM
  • No visibility into what agents are doing in real-time
  • Scattered tools and knowledge with no unified management

With Kortex

  • Sandboxed execution — filesystem, network, and process isolation
  • Privacy-routed credentials — agents never see raw keys
  • Real-time Agent Feed with human-in-the-loop approvals
  • Unified AI Assets hub — tools, skills, knowledge, MCP servers

Security

Sandboxed by default.
Secure by design.

Every agent runs inside an isolated environment with four layers of protection: filesystem boundaries, network policies, process restrictions, and credential routing. See every blocked and allowed action in real-time.

  • Filesystem: bounded read/write paths, no traversal
  • Network: declared hosts only, exfiltration prevention
  • Processes: no root, no sudo, safe syscalls only
  • Privacy: credential proxy routing, full audit trail
Get Started

Up and running in minutes.

Kortex guides you through setup with an interactive onboarding wizard. Point it at your code, connect your LLMs, and start delegating.

1

Add your projects

Point Kortex at your repositories. It auto-detects languages, frameworks, and project structure to give agents the context they need.

$ kortex project add ~/dev/my-app
# Detected: TypeScript, React, Node.js
# Indexed 1,264 files
2

Connect LLM providers

Bring your own models. Connect OpenAI, Anthropic, local Ollama, or enterprise vLLM endpoints on OpenShift AI.

$ kortex provider add openai
$ kortex provider add ollama
# 2 providers configured
3

Start your first task

Describe what you need. Kortex creates a plan, starts executing in a sandbox, and asks you when it needs guidance.

$ kortex task create \
  "Migrate auth to JWT tokens"
# Agent started · Plan: 5 steps
