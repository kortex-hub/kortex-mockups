Coding agents

Choose the default agent runtime for terminal-based work with kdn. You can override this per workspace later. If you use Claude Code through Google Vertex AI, expand OTHER below for the matching agents.json settings.

OpenCode
Local open-source agent — pairs with Ramalama / Ollama on your machine
Recommended
Claude Code
Anthropic Claude in the terminal — use when using a remote / bridged setup
Codex
OpenAI Codex — agentic edits and tool use in the terminal or supported editors
OTHER
Claude with a model from Vertex AI
Use together with Claude Code above — route inference through Google Cloud Vertex AI instead of the Anthropic API

These values map to environment entries for the Claude agent in ~/.kdn/config/agents.json. Run gcloud auth application-default login on the host before starting the workspace.

Mounts (add under claude.mounts in the same file):

No ANTHROPIC_API_KEY is required when using Vertex; credentials come from the mounted gcloud config.
