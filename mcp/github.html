GitHub MCP Server

com.github.mcp · Catalog Not installed
About

GitHub's official MCP Server gives agents full access to the GitHub API through a standard Model Context Protocol interface. Agents can read and write repositories, manage issues and pull requests, trigger Actions workflows, and search code — all via natural language instructions.

Publisher GitHub, Inc. (official)
Source github.com/github/github-mcp-server
Transport stdio (runs as local process)
Install command npx @github/mcp-server
Tools 24 tools across 7 categories
Requires GitHub Personal Access Token (classic or fine-grained)
Capabilities
Repositories
List, create, and inspect repos. Read and write files and branches.
Issues
Create, comment, label, and close issues programmatically.
Pull Requests
Open, review, request reviewers, and merge pull requests.
GitHub Actions
List workflows and trigger runs on any branch or ref.
Releases & Tags
List, create, and publish releases with release notes.
Code Search
Search across all repos for code patterns, symbols, or text.

The configuration below is written to ~/.kdn/config/agents.json under the mcpServers key when you click Install & Configure.

~/.kdn/config/agents.json (excerpt) 
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@github/mcp-server"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "<your-token-from-vault>"
      }
    }
  }
}
