Kaiden CLI Command Reference

Workspace Commands

kdn init [DIR]

Initialize a new workspace in the specified directory

--name <name> Workspace name (default: directory name) --agent <type> Agent type: claude-code, codex, opencode --config <path> Configuration directory (default: DIR/.kdn/)
kdn workspace list

List all running workspaces with context usage

kdn workspace info <id>

Show detailed workspace info and context window

kdn workspace inspect <name>

Inspect workspace resources: sandbox image, assets, network & tokens

--section <name> Show only: sandbox, assets, network, tokens --json Output in JSON format
kdn workspace ssh <id>

SSH into workspace sandbox environment

kdn workspace stop <id>

Stop a running workspace

MCP Commands

kdn mcp list

List connected MCP servers

--available Show all available MCP servers
kdn mcp install <name>

Install MCP server into workspace

--workspace <id> Target workspace ID

Skill Commands

kdn skill list

List available skills

kdn skill info <name>

Show skill details and requirements

kdn skill install <name>

Install a skill (validates hardened image requirements)

OpenShift AI Commands

kdn openshift connect

Connect to OpenShift AI environment

--url <url> OpenShift AI URL --token <token> Authentication token
kdn openshift status

Show OpenShift AI connection status

kdn openshift mcp list

List available MCP servers on OpenShift AI

kdn openshift mcp connect <name|all>

Connect to OpenShift AI MCP servers

kdn openshift skills

List enterprise skills with hardened images
