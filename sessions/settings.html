Network Policies

Control what external resources the sandbox can access through HTTP/HTTPS filtering.

Policy Mode

Choose the default behavior for network requests

Allow Mode

Permit all traffic except what's explicitly blocked. Best for development.

Deny Mode

Block all traffic except what's explicitly allowed. Best for production.

Security Considerations

Network policies control HTTP/HTTPS traffic. Connection to external services over other protocols (raw TCP/UDP) are blocked. Use policies as one layer of security alongside the sandbox isolation.

About Bypass Mode

Bypassed traffic acts as a simple TCP tunnel without content inspection. Use only when necessary for services with certificate pinning. The proxy cannot inject credentials or detect domain fronting for bypassed connections.
