Filesystem, network & deploy

File System Access

Define which directories the agent can access on your host system

Working Directory Only

Agent can only access the specified working directory and its subdirectories.

Home Directory

Agent can access your entire home directory (~/) and all subdirectories.

Custom Paths

Specify exact directories the agent can access.

Full System Access

Agent can access the entire filesystem. Use with caution.

Network Policies

Control what external resources the sandbox can access through HTTP/HTTPS filtering — same options as workspace settings.

Policy mode

Choose the default behavior for network requests

Allow Mode

Permit all traffic except what's explicitly blocked. Best for development.

Deny Mode

Block all traffic except what's explicitly allowed. Best for production.

Security considerations

Network policies control HTTP/HTTPS traffic. Connections to external services over other protocols (raw TCP/UDP) are blocked. Use policies as one layer of security alongside sandbox isolation.
