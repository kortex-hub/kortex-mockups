Settings

Development Environment

Configure how Kaiden integrates with development environments

Enable Red Hat DevSpaces New

Launch Kaiden sessions directly in Red Hat DevSpaces cloud development environments. This enables you to work in pre-configured, containerized workspaces with all your tools ready to go.

DevSpaces URL

The URL of your Red Hat DevSpaces instance. Leave empty to use the default from your OpenShift AI connection.

Default DevSpace Template

Choose the default workspace template when launching new DevSpaces sessions.

Auto-start DevSpaces

Automatically start a DevSpaces workspace when creating a new agent session that requires coding capabilities.

Agent Defaults

Default configuration for new tasks and agents

Default Agent

Default coding runtime for new tasks and the first tab on Coding agents.

Default Profile

The agent profile to apply by default when starting a new task. Profiles bundle skills, MCP servers, and instructions.

Default File Access

The default file system access level for agents in new tasks.

Require Confirmation for File Writes

Ask for confirmation before agents write or modify files.

Auto-execute Commands

Allow agents to execute shell commands without manual approval.

Network & Security

Default network policies and security settings for agents

Default Network Policy

The default network access policy for agent tasks.

Bridge Orchestration

Enable inter-agent communication and orchestration between different AI systems and external services.

OpenShift AI Connection

Enable connection to Red Hat OpenShift AI for centralized model serving, knowledge bases, and enterprise AI assets.

Integrations

Connect external tools and services to extend Kaiden capabilities

GitHub

Connect to GitHub for repository access, issue tracking, and pull request management.

GitHub URL

Use github.com or your GitHub Enterprise instance URL.

Personal Access Token

Generate a token with repo and workflow scopes for full access.

Default Organization/User

The default organization or username for repository operations.

JIRA

Connect to JIRA for issue tracking, sprint management, and project updates.

JIRA Instance URL

Your Atlassian Cloud or JIRA Server instance URL.

Email Address

The email associated with your Atlassian account.

API Token

Generate an API token from your Atlassian account settings.

Default Project Key

The project key to use by default (e.g., PROJ, DEV, PLATFORM).

General

Basic application settings and preferences

Default Model

The default AI model to use for new chat sessions and agent tasks.

Session Auto-save

Automatically save session state and conversation history.

Show Thinking Process

Display the AI's reasoning steps and thought process during responses.

Appearance

Customize the look and feel of Kaiden

Theme

Choose your preferred color theme.

Compact Mode

Reduce spacing and padding for a more compact interface.

Agent Feed

Show the Agent Feed tab in the sidebar. Displays live agent activity, alerts requiring input, and progress across all running workspaces.

Advanced

Advanced configuration options for power users

Enable Debug Mode

Show additional debugging information and logs in the console.

Experimental Features Beta

Enable experimental features that are still in development. These may be unstable.

API Endpoint Override

Override the default API endpoint for custom deployments.
