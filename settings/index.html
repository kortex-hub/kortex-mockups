Settings

Development Environment

Configure how Kortex integrates with development environments

Enable Red Hat DevSpaces New

Launch Kortex sessions directly in Red Hat DevSpaces cloud development environments. This enables you to work in pre-configured, containerized workspaces with all your tools ready to go.

DevSpaces URL

The URL of your Red Hat DevSpaces instance. Leave empty to use the default from your OpenShift AI connection.

Default DevSpace Template

Choose the default workspace template when launching new DevSpaces sessions.

Auto-start DevSpaces

Automatically start a DevSpaces workspace when creating a new agent session that requires coding capabilities.

Modules

Enable or disable optional features and capabilities

Agent Profiles

Enable pre-configured agent profiles that bundle skills, MCP servers, and behaviors for specific roles. Profiles like DevOps Engineer, Platform Engineer, and Security Analyst come with optimized configurations. When disabled, the Profiles tab will be hidden.

Agent Skills

Enable modular skill capabilities for agents. Skills provide domain-specific expertise like Kubernetes management, OpenShift deployment, and custom workflows. When disabled, the Skills tab and agent skill assignments will be hidden.

Bridge

Enable the Bridge module to connect and orchestrate between different AI systems and external services. When disabled, the Bridge tab and related integration features will be hidden.

MCP Tools

Enable Model Context Protocol (MCP) server connections to extend agent capabilities with external tools. When disabled, the Tools tab and MCP server configurations will be hidden.

OpenShift AI Connection

Enable connection to Red Hat OpenShift AI for centralized model serving, knowledge bases, and enterprise AI features. When disabled, the OpenShift AI status bar and connection options will be hidden.

Integrations

Connect external tools and services to extend Kortex capabilities

GitHub

Connect to GitHub for repository access, issue tracking, and pull request management.

GitHub URL

Use github.com or your GitHub Enterprise instance URL.

Personal Access Token

Generate a token with repo and workflow scopes for full access.

Default Organization/User

The default organization or username for repository operations.

JIRA

Connect to JIRA for issue tracking, sprint management, and project updates.

JIRA Instance URL

Your Atlassian Cloud or JIRA Server instance URL.

Email Address

The email associated with your Atlassian account.

API Token

Generate an API token from your Atlassian account settings.

Default Project Key

The project key to use by default (e.g., PROJ, DEV, PLATFORM).

General

Basic application settings and preferences

Default Model

The default AI model to use for new chat sessions and agent tasks.

Session Auto-save

Automatically save session state and conversation history.

Show Thinking Process

Display the AI's reasoning steps and thought process during responses.

Appearance

Customize the look and feel of Kortex

Theme

Choose your preferred color theme.

Compact Mode

Reduce spacing and padding for a more compact interface.

Advanced

Advanced configuration options for power users

Enable Debug Mode

Show additional debugging information and logs in the console.

Experimental Features Beta

Enable experimental features that are still in development. These may be unstable.

API Endpoint Override

Override the default API endpoint for custom deployments.
